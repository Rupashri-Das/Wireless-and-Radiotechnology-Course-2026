# Project 2: Researching Wireless Products and Their Manufacturers

## Assignment Overview

This project involves researching manufacturers of nine wireless products, providing manufacturer links, and describing each product's purpose and key features.

## Key Notes

- All manufacturers listed are **original device/chipset manufacturers**, not distributors or resellers.
- Links point directly to manufacturer product pages with detailed technical specifications.
- Products cover a broad spectrum of wireless technologies: LPWAN (LoRaWAN, NB-IoT, Sigfox), short-range (Zigbee, BLE, UWB), and high-throughput wireless (Wi-Fi 6, Wi-Fi 6E, 5G).
